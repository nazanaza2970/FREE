# FREE

FREE is a desktop-first SSH/SFTP/port-forwarding/VNC workspace, built as a Tauri app with a Rust backend and a React UI.

## Quick start

```bash
npm install
npm run tauri:dev
```

## Build

```bash
npm run build
npm run tauri:build
```

## Tests (Rust)

```bash
cd src-tauri && cargo test
```
